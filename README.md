# MarkMate Website

Static marketing website for selling or renting MarkMate, an attendance management product for companies, colleges, universities, coaching centers, and training teams.

## Run locally

```powershell
npm run dev
```

Then open the local URL printed in the terminal (usually `http://localhost:5173`).

## Customize

- Update the enquiry email in `script.js` by changing `salesEmail`.
- Replace `assets/markmate-dashboard-preview.png` if you want a screenshot from the real attendance app later.
- Edit plan details in `index.html` when your rental or purchase pricing is finalized.
